PDF-Hub favicon assets

Put the files for this app in your website repository root. Add head-snippet.html links inside the <head> element of index.html.
favicon.ico: multi-size browser favicon (16, 24, 32, 48, 64, 128, 256 px)
favicon-16x16.png and favicon-32x32.png: browser favicons
favicon-48x48.png: larger browser/shortcut icon
apple-touch-icon.png: 180 px mobile shortcut icon
icon-192x192.png and icon-512x512.png: larger web/app icon assets
